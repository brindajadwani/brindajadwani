<h3>ScalexAI — Horizontally Scalable AI Task Router</h3>

<p>A distributed task-routing system that directs AI requests to worker instances, monitors service health, and reroutes requests when tools fail.</p>

<ul>
  <li>Built task queues using Redis and persistent storage using PostgreSQL.</li>
  <li>Supported scaling across 10+ worker instances.</li>
  <li>Implemented a distributed circuit breaker and fallback routing.</li>
  <li>Built a live dashboard for queue depth, tool health, and latency.</li>
  <li>Benchmarked throughput using Locust load testing.</li>
</ul>

<p><b>Technologies:</b> Python, FastAPI, Redis, PostgreSQL, Docker, Locust</p>
